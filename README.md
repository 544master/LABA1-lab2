# Лабораторная работа №2 — Модульное тестирование

Состояние проекта: код приложения (LABA1/) не изменён по сравнению
с лабораторной работой №1. Добавлен только тестовый проект LABA1.Tests
с модульными тестами.

## Файлы
- `LABA1/` — исходное приложение «Управление доставкой» (без изменений).
- `LABA1.Tests/DeliveryTests.cs` — тесты класса Delivery.
- `LABA1.Tests/DeliveryManagerTests.cs` — тесты класса DeliveryManager.
- `LABA1.Tests/BoundaryConditionTests.cs` — граничные случаи (пустые поля,
  прошедшая дата) — фиксируют текущее (ещё не исправленное) поведение.
- `LABA1.Tests/UITests.cs` — проверка наличия и состояния элементов формы
  (поиск по тексту кнопки, так как свойство Name будет добавлено только
  в лабораторной работе №6).

## Важно
`Delivery.cs` и `DeliveryManager.cs` были реально скомпилированы
(`dotnet build`, офлайн, .NET 8) в песочнице — ошибок нет. Полный проект
с WinForms и тестовый проект (нужны NuGet-пакеты MSTest) в песочнице без
доступа к nuget.org собрать не удалось — соберите и прогоните в своей
Visual Studio перед сдачей.
